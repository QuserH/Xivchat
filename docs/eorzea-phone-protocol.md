# 艾欧泽亚终端扩展协议

艾欧泽亚终端复用 XIVChat 的加密 TCP 连接和默认端口 `14777`。扩展消息只发送给明确声明支持它的客户端，原版 XIVChat 客户端不会收到未知操作码。

## 能力协商

Android 测试版在 `ClientOperation.Backlog` 的 MessagePack 数组中追加第二个字段 `0x4550`。旧服务器会跳过未知数组字段；艾欧泽亚终端插件识别该标记后，为当前连接启用 `PhoneInventorySupport`。

## 背包快照

- 服务端操作码：`11`
- 消息类型：`ServerInventory`
- 更新方式：连接后立即发送，此后每秒检查一次，只在内容变化时发送
- 当前容器：四个主背包、装备栏、水晶、兵装库、普通及高级陆行鸟鞍囊
- 空槽位：省略

每个物品包含物品 ID、基础物品 ID、数量、容器、槽位、HQ 标记、精炼度或收藏品数值、耐久度及游戏当前语言下的名称。
