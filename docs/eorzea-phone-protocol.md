# 艾欧泽亚终端扩展协议

艾欧泽亚终端复用 XIVChat 的加密 TCP 连接和默认端口 `14777`。扩展消息只发送给明确声明支持它的客户端，原版 XIVChat 客户端不会收到未知操作码。

## 能力协商

Android 测试版在 `ClientOperation.Backlog` 的 MessagePack 数组中追加第二个字段 `0x4550`。旧服务器会跳过未知数组字段；艾欧泽亚终端插件识别该标记后，为当前连接启用 `PhoneInventorySupport`。

## 背包快照

- 服务端操作码：`11`
- 消息类型：`ServerInventory`
- 更新方式：连接后立即发送，此后每秒检查一次，只在内容变化时发送
- 当前容器：四个主背包、装备栏、水晶、兵装库、普通及高级陆行鸟鞍囊
- 空槽位：省略

每个物品包含物品 ID、基础物品 ID、数量、容器、槽位、HQ 标记、精炼度或收藏品数值、耐久度及游戏当前语言下的名称。

## 制作技能、增益与角色三围

- 服务端操作码：`42`，类型 `ServerCraftSkillList`。
- 原有四字段数组继续有效；插件 0.7.41 在末尾追加四个可选整数，Android 0.7.368 开始消费。

| Key | 字段 | 含义 |
| --- | --- | --- |
| 0 | UpdatedUnix | 快照 Unix 秒时间 |
| 1 | Skills | 游戏技能表 |
| 2 | Foods | 当前背包中对制作有效的食物 |
| 3 | Pots | 当前背包中对制作有效的药剂 |
| 4 | ClassJobId | 当前游戏制作职业，8–15；不是配方表的 0–7 索引 |
| 5 | Craftsmanship | 当前面板作业精度 |
| 6 | Control | 当前面板加工精度 |
| 7 | CpMax | 当前制作力上限，不是制作中剩余制作力 |

新增字段缺失、为 nil、非制作职业或任一三围非正数时，客户端忽略三围部分，仍处理技能/食药列表，绝不清空已有配置。超出已知字段的内容继续跳过。

属性每次请求重新读取，不能使用技能表的静态缓存；游戏对象与 PlayerState 当前职业必须一致，避免切职业瞬间串号。收到有效值后走 `PhoneState` 的角色分区，再由同一 `CraftStatsStore` 按 ClassJobId 持久化，工作台和设置不自行建立第二条连接。

当前同步包含装备与当前食药效果。手机不会把同一份三围增益重复叠加到模拟值。角色上线/切换制作职业时主动请求，资料帧周期刷新最多每 30 秒一次；打开工作台或手动同步也可请求。
