# 艾欧泽亚终端更新记录

## Android 0.7.368 / 插件 0.7.41 — 2026-09-06

- 模拟制作移除人工等待 CD，连续技能按制作规则即时执行；远程制作仍以插件 `canAct` 和当前会话状态为准。
- 工作台新增独立制作属性设置，八个制作职业分别编辑、保存；配方准备区不再常驻三围输入框。
- 插件读取当前制作职业的作业精度、加工精度与制作力上限，手机随角色上线、切职业及刷新自动保存；离线可手动设置。
- 属性复用手机既有角色存储分区，角色与职业之间互不覆盖。旧全局设置作为未配置职业的兜底，未读取到有效三围时不会用零值清空配置。
- 新增后续开发规范，明确共享状态、跨功能联动、目录边界、列表性能、协议兼容与发布门槛；石之家高耦合状态和路由保持原状。
- 幻化分享图的装备改为分组单列：固定部位和图标列、完整换行的装备名、逐孔编号的染色信息，左右戒指明确区分；长图预览可滚动，保存/分享按钮固定可见。
- 插件新增独立 GitHub 发布流程，验证标签、包内版本和依赖后发布；库链只在附件可下载后更新。

说明：游戏同步记录的是当前职业的实际面板（包含当时食药效果），不能一次读取未切换到的所有职业；切换到其他制作职业后会分别记住。已开始的模拟使用启动时属性快照。
